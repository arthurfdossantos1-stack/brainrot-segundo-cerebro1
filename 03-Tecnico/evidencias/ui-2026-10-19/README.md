# Evidências recuperadas — não instalar automaticamente

Leia [[03-Tecnico/Recuperacao-UI-2026-10-19]] antes de usar os arquivos.

`local/` preserva os bytes encontrados no disco. `historico/` preserva fontes
extraídas das últimas chamadas concluídas da sessão anterior. O manifesto contém
origem, hashes e caminhos históricos. Tema, loja e HUD diferem entre as versões.

Este anexo não contém o servidor, o mapa, o arquivo de lugar ou todos os scripts.
O repositório continua sendo memória do projeto, sem projeto executável configurado.
Não há sincronização Rojo ou implantação configurada para estes arquivos.

Sintaxe: 10/10 fontes compiladas sem executar. Testes funcionais: não realizados.
