# Checklist de testes do futuro MVP

> **Critérios sugeridos, nenhum teste executado.**

- [ ] Novo jogador começa com base e machado.
- [ ] Árvore fornece madeira corretamente, sem duplicação.
- [ ] Recurso aparece no inventário.
- [ ] Fábrica consome madeira e produz ovo conforme decisão.
- [ ] Ovo entrega Brainrot único de teste.
- [ ] Brainrot gera dinheiro conforme regra.
- [ ] Melhoria comprada atualiza os recursos sem duplicar.
- [ ] Dados persistem, se fizer parte do MVP aprovado.
- [ ] Ações funcionam no celular.
- [ ] Servidor rejeita entradas inválidas.
- [ ] Testes multiplayer foram revisados.
